# Adding a machine from photos

Operate the local tools yourself. Inspect the images with your vision capability. Use the physics library to calculate the forces. There is no model service in the application.

1. Run `python -m resistance_curves prepare bottom.jpg middle.jpg top.jpg --out work/poses`. Use the supplied order from the start to the end of the lifting phase. Read the generated prompt and open every numbered square image.
2. Write `work/poses/observation.json` following that prompt. Mark the visible points in the square image coordinates. Trace the entire load path and explain uncertain identifications in `evidence`. Record the input filenames or photo identifiers in the same order. The rigid lever sample under `catalog/machines` contains a full working observation.
3. For an isolation movement, identify the joint center and proximal/distal segments. Mark an in-plane metric reference in every image and record the length and its basis. An assumed length needs an explicit assumption and a plausible range in the evidence. Without a credible reference keep the force estimate and omit the anatomical fields. Compare plausible alternatives when an uncertain landmark changes the conclusion. Check the force opposes the lifting stroke and document which limb bears it. Use movement “compound” for multi-joint exercises.
4. Run `python -m resistance_curves estimate work/poses/observation.json --plate-kg MASS --out work/review`. Open the labeled overlays and inspect the positions. If a pivot, belt tangent, joint or scale reference misses its target, correct the observation and use a new review directory. Report an unresolved mechanism when evidence is insufficient.
5. Save a reviewed estimate using `python -m resistance_curves record work/poses/observation.json --slug MACHINE-ID --name 'Machine name' --manufacturer 'Manufacturer' --movement elbow-flexion --plate-kg MASS --source 'Photo identifiers, setup, load sharing and limitations'`. The record command stores a fitted resistance function alongside the observations. After correcting an existing record, run `python -m resistance_curves fit catalog/machines/MACHINE-ID.json --write` to refresh its coefficients. Review the sample error and any sparse midrange assumptions. Add an appropriate strength profile under catalog/strength if measurements exist. Keep strength measurements independent from machine force.
6. Run the tests and the Hugo build described in README.md. Review the git diff including new files. Only commit photographs or identifying information when authorized. Version the JSON and templates, with generated HTML kept in the build output.
